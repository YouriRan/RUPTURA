# Cached Liu reference data

These CSV files contain the SI-unit reference traces and markers recovered from Figures 1-7 of Liu et al. The digitization and raster calibration are precomputed: `liu_paper_figures.ipynb` and `reproduce.py` only load these tables and do not process the paper images during normal execution.

The values are graphical reconstructions, not the authors' original numerical data. Dashed lines with open symbols identify these cached Liu references in every plot; solid lines identify RUPTURA results.
