# Inherited material examples

These 14 material-based collections contain 51 simulation inputs for isotherm
fitting, mixture prediction, breakthrough and selected cycles. Their physical and
numerical input settings were retained during the folder move. Subsequent MPD
and cycle additions are included, so the folder name denotes the inherited
collection rather than an exclusive version-1 feature set.

A parsed-JSON duplicate remains between `fe2bdp3-alkanes-C6/iast/simulation.json`
and `CoBDP-alkanes-C6/iast/simulation.json`; both identify CoBDP. Material identity
needs review before either inherited example is removed.

The new HAL launcher selects only `../new_examples/`; it does not submit these
inherited examples.
